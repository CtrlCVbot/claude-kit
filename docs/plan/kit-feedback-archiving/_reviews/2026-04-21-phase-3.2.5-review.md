## 통합 API: `buildFullEntry(input)`

feedback-collector.js에 추가된 main() 통합 함수:

```javascript
buildFullEntry({
  command, runtime, sessionId, startedAt, endedAt,
  transcript, slug, humanCheckpoints, ...
}) → feedback entry (schema v1.0 유효)
```

내부 처리:
1. `extractDomain(command)` → 'plan'|'copy'|'dev'|'core'
2. `buildBaseEntry()` → 최소 엔트리
3. 도메인별 수집기 호출: `plan-collector` / `copy-collector` / `dev-collector`
4. `detectAllIssues()` → issues_observed 배열
5. 최종 엔트리 반환 (ajv 스키마 v1.0 유효)
