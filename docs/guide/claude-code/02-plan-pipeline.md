# Plan Pipeline

> Audience: 기획 파이프라인 사용자
> Related: [../shared/03-first-run-and-daily-workflow.md](../shared/03-first-run-and-daily-workflow.md), [../../30-reference/01-commands.md](../../30-reference/01-commands.md)

`plan` domain은 idea에서 draft, PRD, wireframe, bridge까지 이어지는 planning workflow를 다룹니다.

## 대표 흐름

1. `/plan-idea`
2. `/plan-screen`
3. `/plan-draft`
4. `/plan-prd`
5. `/plan-wireframe`
6. `/plan-design` 또는 `/plan-stitch`
7. `/plan-bridge`
8. `/plan-archive`

## 읽는 기준

- 무엇을 만들지를 정리하려면 plan pipeline으로 갑니다.
- 어떻게 구현할지는 `dev`와 authoring 문서로 갑니다.
- 어떤 source를 믿어야 하는지는 `sync`로 갑니다.
