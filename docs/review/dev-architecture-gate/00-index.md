# Dev Architecture Gate — Review Package

이 폴더는 `docs/guide` 본편에 병합하기 전에 검토하기 위한 리뷰 패키지다. 리뷰 완료 후 개선점을 반영하여 통합 정리된 상태다.

## 목적

- 기획에서 개발로 넘어가기 전에 개발 구조를 먼저 확정하는 게이트를 정의한다
- 이미 구조가 잡혀 있는 프로젝트에서는 feature package가 그 구조를 그대로 따르도록 정합성 규칙을 정리한다
- 본편 문서를 직접 수정하지 않고도 전체 변경 방향을 검토할 수 있게 한다

## 포함 문서

| 문서 | 역할 |
|------|------|
| `00-index.md` | 리뷰 패키지 개요 (이 문서) |
| `01-change-map.md` | 자산 현황 + 기존 자산 수정 포인트 + 병합 체크리스트 |
| `02-patch-proposals.md` | 본편 가이드 5개의 수정안 (카탈로그 수치 수정 포함) |
| `03-review-report.md` | 하네스 적합성 + 구조 호환성 리뷰 결과 |
| `13-dev-architecture-gate.md` | 새 가이드 초안 |

## 리뷰 결과 요약

### 하네스 적합성

모든 실행 자산(명령, 스킬, 훅)이 claude-kit 하네스 규약을 충족한다. 프론트매터, 네이밍, 설치 경로, 훅 이벤트 패턴 모두 기존 자산과 일치.

### 구조 호환성

8개 차원 중 7개 Pass, 1개 Conditional(카탈로그 수치 불일치). 기능 중복 없이 기존 스킬과 보완 관계.

### 주요 발견

- 제안서가 "신규"로 기술한 3개 실행 자산(명령, 스킬, 훅)은 이미 구현 및 등록 완료
- `09-architecture.md` 카탈로그 수치가 실제와 불일치 → `02-patch-proposals.md`에 수정안 반영
