/plan-wireframe

/plan-wireframe은 승인된 PRD를 기반으로 화면 목록, ASCII 레이아웃, Mermaid 네비게이션 흐름, 컴포넌트 명세를 만든다. /plan-design과 /plan-stitch는 이 단계 이후에만 선택할 수 있습니다.

Primary agentplan-wireframe-designer
Main skillplan-wireframe-design
Primary output.plans/wireframes/{slug}/
Next command/plan-design 또는 /plan-stitch

실행 예시

/plan-wireframe {slug}
/plan-wireframe {slug} --revise

Runtime Flow

  1. PRD 로드

    .plans/prd/10-approved/{slug}-prd.md를 읽습니다.

  2. agent spawn

    plan-wireframe-designer가 화면 목록과 흐름을 추출합니다.

  3. 화면별 구조 설계

    ASCII art 레이아웃, 상태, 동작, 반응형 고려사항을 정리합니다.

  4. 네비게이션 작성

    Mermaid 기반 화면 이동 흐름을 기록합니다.

  5. 자동 리뷰

    /plan-review를 통해 wireframe 품질을 검증합니다.

  6. PCC-04

    PRD의 모든 화면이 wireframe에 반영되었는지 확인합니다.

Rules and Guards

Approved PRD gate승인된 PRD 없이 wireframe을 생성하지 않습니다.
PCC-04모든 PRD 화면에 wireframe이 존재하는지 확인합니다.
Post-wireframe branch후속 단계는 /plan-design, /plan-stitch, 또는 skip 후 /plan-bridge입니다.

Failure Modes

  • 승인된 PRD가 없으면 wireframe 생성을 시작하지 않습니다.
  • PRD 화면이 wireframe에 누락되면 PCC-04에서 실패 또는 수정 대상이 됩니다.
  • wireframe 없이 /plan-design 또는 /plan-stitch를 실행하면 거부되어야 합니다.

Next Step

시각 자산이 필요하면 /plan-design {slug}, 통합 검증이 필요하면 /plan-stitch {slug}, 간단한 Feature라면 /plan-bridge {slug}로 이어집니다.
