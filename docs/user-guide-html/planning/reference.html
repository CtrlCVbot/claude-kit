Planning 기능 Reference

이 페이지는 planning pipeline에서 사용하는 agents, skills, hooks, instruction rules를 한곳에 모은 색인입니다. 각 상세 command 페이지를 읽다가 "어떤 기능 자산이 실제로 쓰이나?"가 궁금할 때 이 페이지로 돌아오면 됩니다.

읽는 기준

Claude는 .claude/commands와 .claude/agents 중심으로 실행되고, Codex는 주로 .agents/skills와 .codex/agents 중심으로 같은 업무 흐름을 소비합니다.

Codex 기준

기준설명
Workflow 본체긴 절차는 .agents/skills/*/SKILL.md를 먼저 봅니다.
역할 위임역할이 분명한 작성/리뷰 작업은 .codex/agents/*.toml subagent가 담당합니다.
Instruction반복 지침은 AGENTS.md와 skill guardrail에 반영됩니다.
HookClaude hook과 1:1 동작을 가정하지 않고, Codex 지원 상태를 별도 확인합니다.
Source gapruntime output은 있지만 src/codex/** authoring source가 없으면 manual-review 대상으로 봅니다.
