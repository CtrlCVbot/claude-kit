/plan-screen

/plan-screen은 등록된 IDEA를 RICE 또는 5축 가중 프레임워크로 평가하고 Go, Hold, Kill 판정을 제안한 뒤, 사용자 승인에 따라 idea folder와 index 상태를 전환하는 screening gate입니다.

Runtime Flow

  1. 프레임워크 결정

    --framework, 프로젝트 기본값, rice fallback 순서로 평가 기준을 정합니다.

  2. 대상 확인

    backlog.md에서 IDEA 위치를 찾고 대상 파일을 읽습니다.

  3. agent spawn

    plan-idea-screener가 점수와 Go/Hold/Kill 제안을 생성합니다.

  4. screening 파일 생성

    SCREENING-*.md와 screening-matrix.md를 갱신합니다.

  5. Human checkpoint

    점수 확인 후 승인, 보류, 반려 결정을 사용자에게 요청합니다.

  6. folder transition

    승인 결과에 따라 20-approved 또는 90-archive로 이동합니다.

Rules and Guards

rice-lane-weighted-adjustmentRICE 공식 판정과 Lite/Standard lane 승격 조건의 SSOT입니다.
plan-idea-move-guardidea folder 이동이 허용된 경로인지 검증합니다.
Human CheckpointGo/Hold/Kill 제안은 자동 완료가 아니라 사용자 승인 이후 상태를 전환합니다.

Failure Modes

  • --framework 값이 rice 또는 5axis가 아니면 즉시 실패해야 합니다.
  • IDEA가 backlog index에서 확인되지 않으면 screening을 중단합니다.
  • 이미 screening된 파일을 다른 framework로 재평가하면 기존 결과 보존 정책을 따라야 합니다.
  • 사용자 승인 전에는 approved 상태로 이동하지 않습니다.
