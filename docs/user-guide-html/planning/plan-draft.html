Runtime Flow

  1. 입력 검증

    IDEA가 20-approved에 있고 상태가 approved인지 확인합니다.

  2. agent spawn

    plan-draft-writer가 IDEA와 SCREENING 결과를 로드합니다.

  3. 컨텍스트 수집

    CLAUDE.md, AGENTS.md, architecture 정보를 참조합니다.

  4. 3중 판정

    Lite/Standard, 시나리오 A/B/C, Feature 유형 copy/dev를 명시적 근거와 함께 판정합니다.

  5. routing metadata 생성

    후속 command가 같은 결정을 따라갈 수 있게 routing 정보를 기록합니다.

  6. 자동 리뷰와 checkpoint

    설정에 따라 /plan-review를 호출하고 사용자가 scope를 확인합니다.

Rules and Guards

Approved IDEA gatescreened, on-hold, rejected 상태는 거부합니다.
Routing metadata후속 경로와 override 이력을 기록하는 감사 추적 기준입니다.
plan-review-trigger자동 리뷰 누락을 감지하고 보조 안내합니다.

Failure Modes

  • IDEA가 20-approved에 없으면 draft 생성을 거부합니다.
  • Lite/Standard 판정 근거가 불명확하면 Human Checkpoint에서 보정해야 합니다.
  • Hybrid 감지는 자동 실행이 아니라 후속 레퍼런스 캡처 안내로 이어질 수 있습니다.
  • Blueprint Fast-Track은 blueprint를 실행 SSOT로 쓰지 않고 source spec으로만 참조합니다.

Next Step

Standard dev Feature는 /plan-prd {slug}로 이어집니다. Lite dev Feature는 /dev-feature로 바로 넘어갈 수 있습니다.
