Runtime Flow

  1. 입력 검증

    routing metadata와 Standard category를 확인합니다.

  2. 기획 산출물 확인

    승인 PRD 또는 First Pass, wireframe, stitch 산출물을 수집합니다.

  3. agent spawn

    plan-bridge-writer가 구조 SSOT와 feature binding gate를 확인합니다.

  4. bridge 문서 처리

    wireframe, stitch, context bridge 문서를 생성 또는 갱신합니다.

  5. post-wireframe checkpoint

    design/stitch가 선택되지 않았다면 진행, 선택, skip 여부를 사용자에게 확인합니다.

  6. 다음 경로 결정

    feature type과 hybrid 여부에 따라 /dev-feature 또는 copy reference flow를 안내합니다.

Rules and Guards

Standard onlyLite Feature는 bridge를 생략하고 /dev-feature 또는 reference flow로 직행합니다.
Structure SSOT.plans/project/00-dev-architecture.md가 승인되어 있어야 합니다.
Feature binding00-context/06-architecture-binding.md가 기능별 구조 판단 기준입니다.
Post-wireframe checkpointdesign/stitch/skipped 상태를 routing metadata에 남깁니다.

Failure Modes

  • Lite Feature에서 호출하면 거부하고 더 짧은 경로를 안내합니다.
  • 구조 SSOT가 없거나 승인되지 않았으면 /dev-architecture를 안내합니다.
  • feature binding이 없으면 /dev-architecture {slug}를 안내합니다.
  • routing metadata drift가 감지되면 /plan-draft --rescore를 안내하고 중단합니다.
  • wireframe 후속 단계가 선택되지 않았으면 사용자가 design, stitch, skip 중 하나를 선택해야 합니다.

Next Step

bridge가 통과하면 dev Feature는 /dev-feature {slug}로 이어집니다. copy Feature 또는 hybrid Feature는 /copy-reference-refresh와 병행될 수 있습니다.
