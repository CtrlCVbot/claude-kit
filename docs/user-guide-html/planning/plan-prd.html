/plan-prd

/plan-prd는 First-Pass 문서를 기반으로 10개 섹션 PRD를 작성하고, 리뷰와 Human Checkpoint를 거쳐 승인된 PRD를 다음 wireframe 또는 copy 분석 단계로 넘깁니다.

Primary agentplan-prd-writer
Main skillplan-prd-authoring
Review skillplan-review-criteria
Next command/plan-wireframe

실행 예시

/plan-prd {slug}
/plan-prd {slug} --revise
/plan-prd {slug} --scope
/plan-prd {slug} --detail

Runtime Flow

  1. First-Pass 로드

    .plans/features/drafts/{slug}/first-pass.md를 읽습니다.

  2. agent spawn

    plan-prd-writer가 PRD 10개 섹션을 작성합니다.

  3. 요구사항 ID 채번

    REQ-{feature}-{seq} 형식으로 요구사항을 추적 가능하게 만듭니다.

  4. 자동 리뷰

    /plan-review를 호출해 PRD 품질을 검증합니다.

  5. PCC-03 검증

    기획 범위가 PRD에 반영되었는지 확인합니다.

  6. Human Checkpoint

    승인, 수정, 반려 중 하나로 다음 상태를 결정합니다.

Output Lifecycle

단계파일/폴더작업규칙

Rules and Guards

plan-prd-authoringPRD 10개 필수 섹션과 작성 품질 기준을 제공합니다.
plan-review-criteriaPCC 검증과 승인 전 리뷰 기준을 제공합니다.
plan-doc-guard기획 문서 구조와 형식이 깨지지 않도록 guard 역할을 합니다.

Failure Modes

  • First-Pass 문서가 없으면 PRD 생성을 시작하지 않습니다.
  • PRD 10개 섹션 중 핵심 섹션이 빠지면 승인 전 수정해야 합니다.
  • 요구사항 ID가 없으면 wireframe과 dev handoff에서 추적성이 약해집니다.
  • 시나리오 C에서는 범위 PRD와 상세 PRD를 혼동하지 않아야 합니다.

Next Step

승인된 PRD는 /plan-wireframe {slug}로 이어집니다. 시나리오 C 범위 PRD는 /copy-reference-refresh, 갭 분석, /plan-prd {slug} --detail 순서로 이어질 수 있습니다.
