/plan-review

/plan-review는 아이디어, PRD, wireframe, Feature Package 같은 기획 산출물을 읽기 전용으로 검토하고 PASS, WARN, FAIL 판정을 남기는 품질 게이트입니다.

Primary agentplan-reviewer
Main skillplan-review-criteria
Primary output리뷰 리포트, stage-manifest.json
Next command/plan-revise 또는 다음 승인 단계

실행 예시

/plan-review {path}
/plan-review {path} --type=prd
/plan-review {path} --type=wireframe
/plan-review --pcc {slug}

Runtime Flow

  1. 대상 식별

    리뷰 대상 경로와 문서 유형을 확인합니다.

  2. read-only review

    plan-reviewer가 산출물을 읽고 체크리스트를 적용합니다.

  3. 4축 평가

    완전성, 일관성, 실현가능성, 사용자 중심성을 평가합니다.

  4. PCC 검증

    --pcc 사용 시 단계 간 산출물 일관성을 검증합니다.

  5. severity 분류

    이슈를 CRITICAL, HIGH, MEDIUM, LOW로 나눕니다.

  6. 판정 기록

    통과 시 .plans/stage-manifest.json에 reviewPassed를 기록합니다.

Output Lifecycle

단계파일/출력작업규칙
Input리뷰 대상 산출물읽기수정하지 않음
Input선행 산출물 묶음PCC 비교--pcc 사용 시

Rules and Guards

Read-only review리뷰 대상 파일을 직접 수정하지 않고, 수정은 /plan-revise로 분리합니다.
PCC gateIdea, Screen, Feature, PRD, Wireframe, Stitch, Epic binding의 일관성을 확인합니다.
Bridge pre-check/plan-bridge는 필요한 단계의 reviewPassed 상태를 참조합니다.

Failure Modes

  • 대상 파일이 없으면 리뷰를 시작하지 않습니다.
  • CRITICAL 또는 필수 PCC 불일치가 있으면 FAIL로 판정합니다.
  • reviewPassed가 없으면 다음 단계가 차단될 수 있습니다.

Next Step

수정이 필요하면 /plan-revise로 보정하고, PASS 상태라면 /plan-bridge 또는 /plan-archive로 이어갑니다.
