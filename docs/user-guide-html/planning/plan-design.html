/plan-design

/plan-design은 PRD와 wireframe을 통합해 Claude Code Design용 2단계 프롬프트를 생성하고, 필요하면 결과 URL을 manifest에 등록하는 기본 디자인 파이프라인입니다.

Main skillclaude-design-workflow

Next command/plan-bridge

실행 예시

/plan-design {slug}
/plan-design {slug} --fidelity wireframe
/plan-design {slug} --fidelity high
/plan-design {slug} --register <url>
/plan-design {slug} --ignore-mismatch
/plan-design {slug} --force-sequential --sequential-reason "이유"

Runtime Flow

  1. 입력 검증

    routing metadata, 승인된 PRD, wireframe 디렉터리 존재를 확인합니다.

  2. 배타 게이트 확인

    post_wireframe_path가 stitch이면 순차 실행 사유가 필요합니다.

  3. agent spawn

    plan-design-writer가 PRD와 wireframe을 통합 로드합니다.

  4. 프롬프트 생성

    wireframe 모드와 high fidelity 모드용 프롬프트를 생성합니다.

  5. URL 등록

    --register 사용 시 https://claude.ai URL만 manifest에 등록합니다.

  6. Human Checkpoint

    사용자는 프롬프트 파일을 Claude Design에 붙여넣고 결과 URL을 등록합니다.

Rules and Guards

Wireframe requiredwireframe 없이 호출하면 거부합니다.
Claude URL validation--register는 scheme https, hostname claude.ai만 허용합니다.
Sequential reason/plan-stitch 이후 실행하려면 --force-sequential과 사유가 필요합니다.

Failure Modes

  • routing metadata가 없거나 category: Standard가 아니면 중단합니다.
  • wireframe 디렉터리가 없으면 /plan-wireframe 선행을 안내합니다.
  • PRD와 wireframe 화면 매핑이 맞지 않으면 기본적으로 거부하고 --ignore-mismatch가 있을 때만 경고로 낮춥니다.
  • Claude Design URL이 아닌 값을 등록하려 하면 거부합니다.

Next Step

디자인 프롬프트와 manifest가 준비되면 /plan-bridge {slug}로 개발 handoff를 준비합니다.
