# Feature Idea Brief: guide-sync

- **Epic**: `EPIC-20260527-001`
- **권장 시작점**: `/plan-bridge`
- **idea/screen**: brief

## 문제

Next.js 문서 사이트가 생기면 기존 `docs/guide`, `docs/meta-tooling`, README가 새 docs surface와 충돌하거나 중복될 수 있다.

## 사용자 가치

사용자는 기존 Markdown 문서와 웹사이트 문서 사이에서 혼란 없이 같은 메시지를 확인할 수 있다.

## 범위

포함: 반영 대상 문서 목록, 링크/용어/진입점 정리, 후속 반영 여부 판정.

제외: 구현 중 무분별한 guide 전면 개편.

## 리스크

구현이 확정되기 전에 guide를 먼저 바꾸면 실제 결과와 문서가 어긋날 수 있으므로 마지막 단계에서 반영한다.
