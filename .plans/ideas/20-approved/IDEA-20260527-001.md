## Description

Convert the existing `docs/user-guide-html/**` guide into a Next.js based documentation website while preserving the current HTML guide as reference material.

The website must also document the conversion process itself as a real `claude-kit` pipeline example.

## Expected Value

| Audience | Value |
| --- | --- |
| New users | Easier navigation than a flat HTML package |
| Maintainers | A traceable docs surface for planning and development pipeline examples |
| Claude/Codex users | Clearer explanation of commands, artifacts, and runtime differences |

## Constraints

| Constraint | Detail |
| --- | --- |
| Core first | Website work must not change `src/claude`, `src/codex`, `src/templates`, or `scripts/setup.js` |
| Reference preservation | `docs/user-guide-html/**` remains the source reference for migrated content |
| Pipeline evidence | Each stage must leave prompt, action, artifact, verification, and review records |
| Preview first | Vercel production deployment is out of scope for this run |

## Related Existing Work

The current Next.js implementation under `src/app`, `src/components/docs`, and `src/lib/docs` is treated as prototype/evidence for D2 verification. It is not treated as proof that the pipeline had already been executed.
